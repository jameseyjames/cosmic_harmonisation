# Item-mapping conventions (workbook v0.2)

`curation/COSMIC_Item_Mapping_Pilot_v0.2.xlsx` is generated by `curation/build_item_mapping.py`. To change a mapping, edit the `add()` calls (or the `NEW` registry for c-codes) and re-run the script. Don't hand-edit the xlsx.

## Tabs
- **ReadMe**
- **Items:** HCAP Items columns plus COSMIC columns (see below).
- **Coverage:** code × cohort matrix. ✓ = item-level source; ◐ = subtest or total.
- **Code_registry**
- **Studies**
- **Domains_and_subdomains:** copied from HCAP.
- **Excluded:** variables reviewed but not mapped, with the reason.
- **Open_questions**

## Items columns
**HCAP columns:** item, item_label, study, domain, subdomain, curator (JL), source_file, source_item, source_labels, code1, code2, possible_range, coding_notes, notes_comparability, Linking Confidence to HRS-HCAP, similar_items, original_question_text.

**COSMIC additions:**
- HCAP studies with this code
- Link status (dropdown): Proposed anchor – for Delphi / New COSMIC item – link to be decided / Agreed anchor / Rejected
- Administration / language notes
- Waves
- Level (Item / Subtest / Total)
- Delphi priority (High / Medium / Low)

## Coding rules
1. **Reused HCAP u-code** = the item looks equivalent to that HCAP item, so it is a *proposed* anchor (HCAP convention: same code means an assumed anchor).
   - Domain and subdomain are inherited from HCAP unchanged, even where contested; the disagreement goes in the notes.
   - Linking confidence to HRS-HCAP: 2 = confident, 1 = tentative, −1 = the HCAP item isn't in HRS-HCAP and links to another HCAP study.
2. **COSMIC-new `c###` codes** are for items with no HCAP equivalent.
   - The first digit is the domain: 1 orientation, 2 memory, 3 executive, 4 attention/speed, 5 language/fluency, 6 visuospatial, 9 global/total.
   - Two cohorts sharing a c-code = a proposed within-COSMIC anchor (e.g. **c241**, the CSI-D 3-word delayed recall, in SPAH, MYNAH and Uganda).
3. **code2 `sum_source`** = the analytic variable is the sum of the listed source items.
4. **No copyrighted content:** no word lists or story text.
5. **Modality matters.** A CERAD list read aloud only (MYNAH, SPAH) takes HCAP's verbal codes **u202/u211**, not HRS-HCAP's visual-cue codes u201/u210.
6. **Scope:** primary scores only. Process scores (intrusions, perseverations, clustering), cohort z-scores and domain scores, clinical ratings (CDR), literacy measures and RMET are listed on the Excluded tab.
7. Source variable names come from the cohort files held by COSMIC (names and labels only). Entries marked **TBC** or **ASSUMED** need checking against protocols.

## v0.2 summary (13 Nov 2026)
- 154 rows: MYHAT 42, MYNAH 34, SPAH 34, HELIAD 22, KLOSCAD 15, Uganda 7.
- 95 codes, of which 41 are HCAP u-codes. 37 codes appear in two or more cohorts.
- 150 rows have a source variable confirmed in the cohort file. Two are inferred, one is unidentified and one is missing from the file; all four are flagged.
- **Strong bridges:**
  - Community Screening Instrument for Dementia items (elbow, hammer, local market, the pointing command, three-word recall) link SPAH, MYNAH and Uganda to each other and, through HCAP's codes, to the HCAP studies.
  - MYHAT's item-level MMSE supplies most of the HRS-HCAP anchors.
- **Weak link:** HELIAD has only an MMSE total, and its semantic fluency category is objects, not animals.
